# Adopters

This file lists organizations that use myriarch. Adopters help the project and its future maintainers to understand who
depends on it, which scenarios matter and where the documentation needs work. Listing is voluntary, and you decide how much
to say.

## Add your organization

Open a pull request that adds one row to the table below, in alphabetical order by organization. You may add a row only for
your own organization, or for one you are authorized to speak for. Please keep the use case short and factual (for example
"around 400 collectors on edge sites, rollouts by wave"). The contact is a public contact such as a team page or a GitHub
account; do not add private e-mail addresses.

If you prefer not to be named, you can describe your use anonymously (for example "a logistics company"), or tell us in an issue
and we will count you without listing you.

Like every contribution, the pull request needs a DCO sign-off, see [CONTRIBUTING.md](CONTRIBUTING.md).
