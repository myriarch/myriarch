Myriarch is an open-source fleet manager for OpenTelemetry Collectors, built on OpAMP. This section is about the project itself:
where it is going, how it is run, how to take part and how it is built. The product documentation is under
[Documentation](/docs/).

## Get in touch

Questions, bug reports and ideas go to the [issue tracker](https://github.com/myriarch/myriarch/issues). Read
[Contributing](/project/contributing/) before you send a change. Report a vulnerability privately, as described in the
[security policy](/project/security/), never in a public issue.
