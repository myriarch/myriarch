# License overrides for Go modules whose license go-licenses cannot classify or reports ambiguously.
#
# Shared by ci/check-release-licenses.sh (release license allowlist) and scripts/gen-third-party-notices.sh
# (THIRD_PARTY_NOTICES). Every entry was checked by reading the license file of the module.
#
# Format: one entry per line, six fields separated by "|"; "#" starts a comment line, empty lines are ignored.
#
#   <package path prefix>|<license go-licenses reports>|<license to declare>|<license file>|<scope>|<reason>
#
# - The prefix matches the package path itself or any package below it ("<prefix>/...").
# - The scope is "*" (every package below the prefix) or a comma-separated list of exact import paths. With a list the
#   entry fails closed: go-licenses names a library after the module root, so it cannot tell which package of the module
#   carries the reported license. If a build links a package of the prefix that is not in the list, the notices generator
#   and ci/check-release-licenses.sh fail until the package is reviewed and the entry is changed.
# - The entry applies only to packages for which go-licenses reports exactly the second field.
# - The declared license must be on the list "release" of ci/license-allowlist.txt, the allowlist of ci/check-release-licenses.sh.
# - The license file is relative to the module root. "-" keeps the file that go-licenses reports (its whole directory
#   is reproduced in THIRD_PARTY_NOTICES).
# - An entry that matches no package of the linked builds is stale and makes the notices generator fail.
#
# go-licenses cannot classify these LICENSE files; each one is the short Apache License 2.0 notice, not the license text.
