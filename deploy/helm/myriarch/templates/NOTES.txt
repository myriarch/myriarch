Upgrading from a version before migration 00003 (user identity from provider+issuer+subject): old replicas can no
longer store OIDC logins once the migration has run. For this upgrade scale down to one replica
(replicaCount=1), upgrade, then scale up again; during a rolling update OIDC logins fail on old replicas until all
replicas are updated (existing sessions, agents and API tokens keep working).

Prerequisites (see values.yaml): Secret "{{ .Values.existingSecret }}" containing database-dsn (and the other files you
reference), PostgreSQL without PgBouncer transaction pooling, WebSocket-capable access with long timeouts.
