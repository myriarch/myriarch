## myriarch-updater licenses

Print the license of myriarch, or with --third-party the notices of the included software

### Synopsis

Prints the Apache-2.0 license text of myriarch. With --third-party it prints THIRD_PARTY_NOTICES instead: the license texts and NOTICE files of the third-party software that the myriarch binaries include.

```text
myriarch-updater licenses [flags]
```

### Options

```text
  -h, --help          help for licenses
      --third-party   print the third-party notices instead of the project license
```
