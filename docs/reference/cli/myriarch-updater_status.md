## myriarch-updater status

Show the service state (and, with --config, the installed collector version)

```text
myriarch-updater status [flags]
```

### Options

```text
  -c, --config string   updater.yaml (prints installed collector versions and the supervisor link)
  -h, --help            help for status
```
