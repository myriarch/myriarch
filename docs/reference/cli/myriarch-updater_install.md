## myriarch-updater install

Install myriarch-updater as OS service (systemd unit / Windows service)

```text
myriarch-updater install [flags]
```

### Options

```text
  -c, --config string   path to updater.yaml
  -h, --help            help for install
      --start           start the service after installing
```
